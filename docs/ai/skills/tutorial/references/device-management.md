# 设备管理

平台上设备分为三种类型：**直连设备**、**网关设备**、**网关子设备**。区分它们的核心在于：真正产生数据的设备是否具备联网能力，能否与平台直接通信。

| 类型 | 判断标准 | 示例 |
|------|---------|------|
| **直连设备** | 产生数据，且可直接与平台 TCP/MQTT 通信 | 数控机床（CNC）、支持 TCP 的仪表 |
| **网关设备** | 本身不生产数据，负责转发子设备数据 | PLC、DTU 网关、Modbus 网关 |
| **网关子设备** | 产生数据，但需通过网关间接与平台通信 | PLC 下挂的传感器、Modbus 从站仪表 |

> **举例：** 一台数控机床 CNC，其内部有 PLC 控制，但 PLC 与机床是一体的，数据最终由 CNC 产生，且平台可直接通过 TCP 连接 CNC，因此 CNC 属于**直连设备**。而独立的 PLC，它本身不产生业务数据，数据来自它下挂的传感器或仪表，且这些传感器不能直接联网，必须通过 PLC 转发，因此 PLC 是**网关设备**，它下面的传感器是**网关子设备**。

> **关于产品和设备类型的匹配：**
> - **直连设备** — 选择**直连产品**（有物模型）
> - **网关子设备** — 选择**子产品**（有物模型）
> - **网关设备** — 选择**父产品（网关产品）**（无物模型，仅做数据转发）
>
> 详见[产品配置与物模型](./product-config.md)中关于三种产品类型物模型有无的说明。

## 直连设备

**菜单：设备管理 → 直连设备**

产生数据的设备直接与平台通信，不经过其他网关：

1. 点击"新增"
2. 选择所属产品（自动继承物模型和协议）
3. 填写设备编号（需与实际设备一致）、设备名称
4. 保存

| 页面 | 说明 |
|------|------|
| **网关设备** | 创建网关设备，配置通信参数 |

## Modbus 批量采集

**启用方式：** 配置 Modbus 网关子设备时，可选择启用批量采集。

手动模式下每个采集点需单独配置一条指令，点位多时效率低。启用批量后，平台自动完成：

1. **按功能码分组** — 将设备下所有采集点按 Modbus 功能码（如 01 读线圈、03 读保持寄存器）分成不同组
2. **地址排序合并** — 同一组内地址从小到大排序，连续地址区间合并成一条批量请求
3. **按包长拆分** — 合并后的区间超过单包最大长度限制时，自动拆分为多次请求

配置好采集点位后开启批量，剩下由平台自动处理。
