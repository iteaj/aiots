# 整体流程与快速入门

## 整体流程

接入物联网设备的典型流程：

```
协议驱动配置 → 产品配置（定义物模型）→ 设备管理（创建设备）→ 运行管控（监控数据）
```

> **💡 简化说明：** 对于内置驱动（Modbus、PLC、OPC UA 等），其网络组件和默认网关产品都已预置，接入设备时**直接从创建直连产品或子产品开始**即可，无需配置网络组件和网关产品。详见[产品配置与物模型](./product-config.md)中的说明。

## 快速入门示例

**场景：接入一个温度传感器**

**步骤 1：确认驱动**

传感器使用 Modbus RTU 协议，平台已有 Modbus 驱动，无需额外配置。

**步骤 2：创建产品**

基础信息 → 产品配置 → 新增：
- 名称：智能温度传感器
- 产品类型：传感器
- 协议驱动：Modbus

**步骤 3：配置物模型**

在产品列表点击"物模型"，新增属性：
- 属性名称：温度 | 标识符：temperature | 类型：float | 单位：℃ | 只读

**步骤 4：配置事件模型**

在产品物模型编辑页，新增事件模型（采集器）：
- 接口名称：温度采集 | 标识符：tempCollect
- 上行配置：`@`选择 temperature 属性完成绑定
- 频率标签：5s

**步骤 5：创建设备**

设备管理 → 直连设备 → 新增：
- 选择产品：智能温度传感器
- 设备编号：TEMP-001 | 名称：车间温度传感器

**步骤 6：配置采集器（事件源）**

事件规则 → 事件源 → 新增：
- 事件类型：采集器
- 产品列表：选择智能温度传感器
- 频率范围：选择 5s（匹配事件模型的频率标签）

**步骤 7：查看数据**

- 运行展板：查看实时温度
- 数据中心：查看历史温度记录
- 若超阈值，可在告警中心配置告警规则
