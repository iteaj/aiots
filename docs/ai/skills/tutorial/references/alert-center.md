# 告警中心

## 告警配置

**菜单：告警中心 → 告警配置**

定义告警触发规则。当前告警规则已移至**物模型属性编辑页**的"告警/指标配置"选项卡进行配置（详见[产品配置与物模型](./product-config.md#配置物模型属性)），单属性告警在此处集中管理。告警中心主要用于查看告警模板和告警记录。

## 告警模板

**菜单：告警中心 → 告警模板**

配置通知消息格式，支持自定义内容模板。

## 告警记录

**菜单：告警中心 → 告警记录**

查看所有告警的历史记录，支持按设备、时间、级别筛选。告警由告警配置触发，区分方式可通过判断告警配置是否设置了运算符和阈值来识别（有运算符和阈值的为属性指标告警，否则为场景联动等其他类型告警）。
