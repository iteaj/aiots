# DTU 私有协议物模型配置参考

> **驱动源码：** `DtuPrivateProtocolSupplier.java`

## 驱动信息

| 字段 | 值 |
|------|-----|
| 协议编码 | `DTU_PRIVATE` |
| 通信方式 | TCP |
| 采集模式 | 公共模式 (COMMON) |

> DTU 私有协议为公共模式，事件模型用于配置**读取设备数据**，功能模型用于**向设备写入数据**。

## 可选指令

### 事件模型（读指令）

| 指令编码 | 说明 | 操作类型 |
|---------|------|---------|
| `read` | 读数据 | R |

### 功能模型（写指令）

| 指令编码 | 说明 | 操作类型 |
|---------|------|---------|
| `write` | 同步写（写完等待设备响应） | W |
| `asyncWrite` | 异步写（写完直接返回） | W |

## 指令与上下行配置项

### read（读数据）

| 方向 | protocol_attr_field | 配置说明 |
|------|-------------------|---------|
| DOWN | `type` | 下发内容格式：string（字符串）/ hex（十六进制） |
| DOWN | `data` | 下发给设备的读指令 |
| UP | `value` | 设备返回的数据，配置值填 `@属性字段` 绑定到物模型属性 |

### write / asyncWrite（写数据）

| 方向 | protocol_attr_field | 配置说明 |
|------|-------------------|---------|
| DOWN | `type` | 写内容格式：string（字符串）/ hex（十六进制） |
| DOWN | `data` | 写给设备的数据 |

## 网关设备配置

网关配置由网络组件参数决定（`getNetworkConfig()`），创建网络组件时配置：

| 字段 | 必填 | 说明 |
|------|------|------|
| `host` | 是 | 绑定的网卡 IP，`0.0.0.0` 表示全部 |
| `port` | 是 | 监听端口 |
| `readIdle` | 是 | 读空闲(秒) |
| `messageType` | 是 | 注册码类型：ASCII/HEX |

## 子设备配置

DTU 私有协议无额外子设备 config 配置。

## device_sn 说明

- 子设备的 `device_sn` 是设备唯一标识
- 同一网关下的子设备 `device_sn` 必须唯一
