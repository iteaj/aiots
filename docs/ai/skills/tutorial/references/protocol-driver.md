# 协议驱动配置

**菜单：基础信息 → 协议驱动**

协议驱动负责"翻译设备的语言"——它了解设备的数据格式和通信协议，将设备的原始数据解析为平台能理解的物模型属性值，也负责将平台下发的指令翻译成设备能识别的命令。平台内置的驱动：

| 驱动 | 适用设备 | 通信方式 |
|------|---------|---------|
| Modbus | Modbus RTU/TCP 设备 | 串口/TCP |
| DTU | DTU 透传模块 | TCP |
| MQTT | MQTT 协议设备 | TCP |
| OPC UA | OPC UA 服务器 | TCP |
| PLC（西门子/欧姆龙/三菱/罗克韦尔/汇川等） | PLC 设备 | TCP |
| Fanuc CNC | 发那科数控机床 | TCP |
| DLT645 | 国家电网电表 | 串口/TCP |
| IEC104 | 电力远动设备 | TCP |
| IEC61850 | 变电站智能设备 | TCP |
| 自定义脚本驱动 | 私有协议设备 | 自定义 |

内置驱动对应的网络组件和网关产品都已预置，接入设备时直接创建直连产品或子产品即可，无需重复配置网络组件和网关产品（详见[产品配置与物模型](./product-config.md)中的说明）。

**配置步骤：**

1. 进入 **基础信息 → 协议驱动**
2. 点击"新增"，选择驱动类型
3. 填写驱动参数（端口号、协议参数等）
4. 保存即注册到平台
