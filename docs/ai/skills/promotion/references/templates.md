# 文案模板

## 公众号推文模板

```
标题：{痛点场景}？{解决方案}帮你搞定

正文结构：

一、开头：场景切入
- 描述一个真实痛点场景（工厂巡检耗时、设备故障发现滞后等）
- 引发读者共鸣

二、痛点放大
- 传统做法的问题所在（人力成本高、被动响应）
- 为什么需要改变

三、解决方案
- 平台核心能力（零代码接入、告警推送、多端查看）
- 具体怎么解决上述痛点
- 配截图或架构图

四、效果数据
- 接入设备的时间对比（天 → 小时）
- 告警响应速度提升
- 减少开发工作量

五、结尾引导
- 免费试用 / 预约演示 / 联系我们
- 留下联系方式或关注公众号引导
```

## 技术文章模板

```
标题：{技术主题}的{新思路/实践}

正文结构：

1. 背景
   - 行业普遍面临的问题
   - 传统方案的局限性

2. 设计思路
   - 为什么采用模型驱动架构
   - 与传统编码方式的区别

3. 实现方案
   - 架构图 + 核心模块说明
   - 关键技术选型理由

4. 实战示例
   - 一个具体的设备接入场景
   - 配置步骤和最终效果

5. 总结与展望
   - 方案的优势总结
   - 未来演进方向
```

## 社交媒体短文案模板

```
短文案（朋友圈/群聊）：

{一句话痛点}？{我们的方案}。
{核心优势 1}，{核心优势 2}，{核心优势 3}。
{引导语} {链接/二维码}

示例：
还在为设备数据采集发愁？试试 IUCY-AIoT。
内置 Modbus/PLC/OPC UA 等主流驱动，零代码接入。
告警自动推送到手机，不用满车间跑。
点击免费试用 → {链接}
```

## 案例故事模板

```
标题：{客户行业}企业如何用{方案}实现{效果}

正文结构：

1. 客户背景
   - 行业、规模、业务特点

2. 痛点与挑战
   - 改造前存在的问题
   - 为什么选择我们的方案

3. 解决方案
   - 接入哪些设备
   - 配置了什么告警规则
   - 用到了哪些特色功能

4. 实施效果（用数据说话）
   - 接入设备数量
   - 节省人力/时间
   - 故障响应速度提升
   - 投资回报率

5. 客户评价（一句话）
```
