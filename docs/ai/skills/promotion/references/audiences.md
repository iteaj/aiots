# 目标受众与文案策略

## 1. 工厂负责人 / 老板

**身份标签：** 生产厂长、设备部长、制造企业老板
**核心诉求：** 降本增效、减少停机、省人省心
**常见痛点：**
- 设备越来越多，每天巡检占用人手太多
- 设备出故障了才知道，被动响应非常被动
- 买了好几个系统，数据不通、互不连通
- 想上 IoT 但觉得太复杂、太贵

**文案切入点：**
- 一台设备从接线到出数据只需要几个小时
- 手机上就能看到全厂设备状态，不用满车间跑
- 告警自动推送到手机，故障第一时间知道
- 不用养专门的 IT 团队也能用起来

## 2. 技术负责人 / CTO

**身份标签：** 技术总监、研发经理、IT 负责人
**核心诉求：** 架构先进性、扩展性、稳定性
**常见痛点：**
- 市面 IoT 平台太重，部署和维护成本高
- 设备协议不统一，每个项目都在写定制驱动
- 担心供应商锁定，希望平台开放可扩展
- 需要一个能支撑未来 3-5 年发展的技术底座

**文案切入点：**
- 模型驱动架构：物模型定义设备行为，非侵入式设计
- 开放 SPI 接口，支持自定义驱动扩展
- 联动脚本引擎支持任意复杂业务逻辑
- 轻量化部署，不依赖重型中间件

## 3. 系统集成商 / SI

**身份标签：** 自动化集成商、项目交付团队、解决方案商
**核心诉求：** 交付速度、项目利润、方案复用
**常见痛点：**
- 每个项目都要从头开发，重复造轮子
- 定制开发工作量大，项目利润率低
- 多个项目维护不同代码版本，运维成本高
- 客户需求变化频繁，改代码来不及

**文案切入点：**
- 一次配置，多个项目复用（产品/物模型模板）
- 零代码接入，减少定制开发工作量 60% 以上
- 管理端和移动端界面自动生成，无需单独开发
- 面向私有化部署，可嵌入客户整体方案
